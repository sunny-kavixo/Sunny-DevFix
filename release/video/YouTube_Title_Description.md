### Key Technical Capabilities

1. NVIDIA Nemotron Reasoning: Deep causal diagnosis across multi-frame Python runtime stack traces via Nebius Token Factory serverless API.
2. Live Code Guardian: Instant in-editor AST syntax linter providing line-level diagnostics as you type completely offline.
3. Token-Bound Approval Gate: Zero silent file overwrites; every disk modification requires human review and an ephemeral single-use token.
4. One-Click Instant Rollback: Every applied patch issues a rollback token to immediately restore exact pre-patch bytes.
5. Disposable Docker Sandbox: Twin reproductions execute side-by-side with dropped Linux capabilities, read-only root, and zero network access.
6. 100% Offline Deterministic Fallback: Automatically falls back to local AST engine when API keys are absent, ensuring development is never blocked.
